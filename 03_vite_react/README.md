# 03_vite_react: Vite 첫 화면 실습 (section04)

`C:\Users\user\Downloads\practice\daily\07_01\source_code\onebite-react-v2\section04` 기준의 React 첫 화면 실습 폴더입니다.

## 🚀 빠른 시작 가이드

이 폴더에서 직접 실습을 진행하려면:

```powershell
# 1. 03_vite_react 폴더로 이동
cd 03_vite_react

# 2. Vite 기본 React 프로젝트 생성 (JavaScript 템플릿)
npm create vite@latest . -- --template react

# 3. 의존성 설치
npm install

# 4. 개발 서버 실행
npm run dev
```

브라우저(`http://localhost:5173`)가 열리면 `src/App.jsx`를 열어 `<h1>안녕 리액트!</h1>`로 제목을 수정하고 화면의 즉각적인 변화(HMR)를 관측합니다.
