# TodoList 실습 시작점

원본 `onebite-react-v2/section08/chapter1`을 기준으로 만든 React + Vite 프로젝트입니다.
지금은 `TodoList` 글자만 보이는 첫 단계이며, 기능 구현 코드는 넣지 않았습니다.

## 실행하기

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다.

## 파일 안내

- `index.html`: 브라우저가 처음 여는 HTML
- `src/main.jsx`: React 앱의 시작점
- `src/App.jsx`: 지금부터 편집할 첫 컴포넌트
- `src/App.css`, `src/index.css`: 스타일 파일
- `src/components/`: 이후 강의에서 만들 `Header`, `Editor`, `List`, `TodoItem` 컴포넌트를 둘 폴더

다음 실습은 `src/App.jsx`의 `TodoList`를 원하는 화면으로 바꿔 보세요.
